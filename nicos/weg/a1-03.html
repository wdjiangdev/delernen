🗣 第三步 · 跟读对话（把剧情压缩成 1 分钟）

Kellner: Guten Tag! Was hätten Sie gern?

Nico: Guten Tag. Ich hätte gern eine Pizza.

Emma: Und ich nehme einen Salat.

Kellner: Möchten Sie etwas trinken?

Nico: Ja, ein Wasser, bitte. Und du, Emma?

Emma: Einen Apfelsaft, bitte.

Kellner: Gerne. Einen Moment, bitte.

Nico: Zahlen, bitte! Wie viel kostet alles zusammen?

Kellner: Das macht 15 Euro 80.

练法：三个角色轮着演，重点练 hätte gern 的语气——它比 ich will 礼貌得多，德国点餐全靠它。Das macht …（一共……钱）是报总价的固定说法，先整句记下。

📐 第四步 · 语法一页讲透

1）规则动词变位：词干 + 人称尾巴（完整版）

第 1 课的规律现在补全：规则动词去掉词尾 -en 得到词干，再加人称尾巴 -e / -st / -t / -en / -t / -en：

人称machen 做trinken 喝arbeiten 工作
ichmachetrinkearbeite
dumachsttrinkstarbeitest
er / sie / esmachttrinktarbeitet
wirmachentrinkenarbeiten
ihrmachttrinktarbeitet
sie / Siemachentrinkenarbeiten

注意 arbeiten：词干以 -t 结尾，du / er / ihr 形式要垫一个 e（du arbeitest），不然根本读不出来。warten、antworten 同理。

2）essen 是例外：e 变 i

essen 的 du 和 er / sie / es 形式里，词干的 e 要变成 i：

ichduer / sie / eswirihrsie / Sie
esseisstisstessenesstessen

Was isst du? — Ich esse eine Pizza. 这类「换元音」的不规则动词后面还会遇到：geben → gibt、sprechen → sprichst（第 4 课），规律都是只变 du 和 er / sie / es 两格。

3）点单神器：möchten 与 hätte gern

möchten（想要）是点单和提要求的礼貌说法：ich möchte, du möchtest, er möchte, wir möchten, ihr möchtet, sie möchten。例：Ich möchte einen Kaffee. 餐厅里更地道的说法是 Ich hätte gern …（我想要……），后面直接跟宾格名词：Ich hätte gern eine Pizza / einen Salat。服务员反问你：Was hätten Sie gern? 暂时不想吃喝就说：Nein, danke. Ich habe keinen Hunger / keinen Durst.（Hunger 饿、Durst 渴，先认脸）

4）宾格入门：为什么点单时名词会变样

动词后面的直接宾语用宾格（Akkusativ）。好消息是：只有阳性名词变脸，阴性、中性、复数全都不变：

性主格（菜单上）宾格（点单时）
der 阳性der / ein Kaffeeden / einen Kaffee
die 阴性die / eine Pizzadie / eine Pizza
das 中性das / ein Wasserdas / ein Wasser

所以点单时只要盯住阳性词：einen Kaffee, einen Tee, einen Saft, einen Salat。价格问法：Wie viel kostet die Pizza? — Sie kostet 8 Euro 50. / Was kostet das?

✍️ 第六步 · 自测（5 题，全对再往下走）

🎙 口语任务（本课的「过关标准」）

在脑子里开一家小餐厅，自己演服务员和客人各一遍，说完这段点单全流程：

  • Guten Tag! Was hätten Sie gern?
  • Ich hätte gern ______（食物）.
  • Und ______（饮料）, bitte.
  • Wie viel kostet das?
  • Das macht ______ Euro. Zahlen, bitte!

全程不用 ich will、点单都用 hätte gern + bitte，价格能听懂到 Cent，这课过关。
