Modalverb

Konjugation

  • Präsens: lern e / lern st / lern t / lern en / lern t / lern en
  • 中：现在时词尾：ich lerne / du lernst / er lernt / wir lernen / ihr lernt / sie lernen。
  • Präteritum: Imperfekt, Vergangenheitsform
  • 中：过去时（又叫 Imperfekt）。
  • Perfekt: sein/haben + Partizip II
  • 中：现在完成时 = sein/haben + 第二分词（Ich habe gelernt. / Ich bin gefahren.）
  • Plusquamperfekt: waren/hatten + Partizip II
  • 中：过去完成时 = war/hatte（的变位形式）+ 第二分词（Ich hatte gelernt. / Ich war gefahren.）
  • Futur I: werden + Infinitiv
  • 中：将来时 = werden + 不定式（Ich werde lernen.）
  • Futur II: werden + Partizip II + sein/haben
  • 中：将来完成时 = werden + 第二分词 + sein/haben（Ich werde gelernt haben.）

Sätze

中：句子层面。

  • Stellung der Satzglieder: Word order in a sentence: TKML
  • 中：句子成分的位置：状语顺序 TKML（Temporal 时间 → Kausal 原因 → Modal 方式 → Lokal 地点，即常说的 TeKaMoLo）。例：Ich fahre morgen wegen der Arbeit mit dem Zug nach Berlin. 我明天因为工作坐火车去柏林。
  • Satzverbindungen (Konnektoren): Zweiteilige Konnektoren
  • 中：句子连接：双部连词（sowohl … als auch、weder … noch、entweder … oder 等）。
  • Connectors around to, without to, (instead of) to, infinitive and alternatives
  • 中：um…zu / ohne…zu / (an)statt…zu 不定式结构及其从句替换（damit / ohne dass / anstatt dass）。
  • Konnektoren: andernfalls, demnach, folglich, sonst, somit
  • 中：结果连接副词（否则、据此、因此、否则、这样一来）。
  • Konditionale Konnektoren: wenn, falls, außer wenn + Nebensatz, es sei denn + Hauptsatz
  • 中：条件连词：wenn / falls（如果）；außer wenn + 从句、es sei denn + 主句（除非）。
  • Konnektoren: Konsekutive, adversative und temporale Konnektoren
  • 中：结果、转折、时间类连接词。
  • Conjunction: "während" ("while")
  • 中：während 作连词（"在……的时候 / 而"）。
  • Modal sentences with thereby, that and by
  • 中：方式从句：dadurch, dass / indem（通过……方式）。

  • 中：用 wenn 还是 als？（原文 "order" 应为 "oder"。als＝过去一次性；wenn＝反复/现在/将来。）

Präpositionen

  • Präpositionen + Akkusativ: bis, durch, entlang, für, gegen, ohne, um wider.
  • 中：支配四格：bis 直到、durch 穿过、entlang 沿着（后置时四格）、für 为了、gegen 反对、ohne 没有、um 围绕、wider 违背。
  • Präpositionen + Dativ: ab, aus, außer, bei, entgegen, gegenüber, mit, nach, seit, von, zu.
  • 中：支配三格：ab 从…起、aus 从…出来、außer 除了、bei 在…处、entgegen 违背/迎着、gegenüber 对面、mit 和/用、nach 之后/去、seit 自从、von 从/关于、zu 到。
  • Wechselpräpositionen: an, auf, hinter, in, neben, über, unter, vor, zwischen.
  • 中：双向介词（静三动四）：静止位置用三格，方向移动用四格。
  • Präpositionen + Genitiv: außerhalb, innerhalb, laut, mithilfe, statt, strotz, während, wegen
  • 中：支配二格：außerhalb 在…之外、innerhalb 在…之内、laut 根据、mithilfe 借助、statt 代替、trotz 尽管（⚠ 原文 "strotz" 为笔误）、während 在…期间、wegen 因为。
  • Präpositionen mit temporaler Bedeutung: Zeit
  • Präposition → Adverb → Konnektor: temporal
  • Präposition → Adverb → Konnektor: kausal, konsekutiv, konzessiv, adversativ
  • Präposition → Adverb → Konnektor: modal, konditional, final

中：时间介词；以及同一语义的"介词 → 副词 → 连词"三种表达（如 wegen → deshalb → weil；trotz → trotzdem → obwohl）。

中文要点

  • 这是 A1–C1 的语法总索引，当"地图"用，不必背；每学完一个点回来打个勾。
  • 先记熟两样每天都用的：状语顺序 TKML（TeKaMoLo：时间—原因—方式—地点）和介词支配的格（四格、三格、三/四格、二格四组）。
  • 过去完成时 = war / hatte 的变位形式 + 第二分词（Ich hatte gelernt. / Ich war gefahren.）。
  • 二格介词（trotz、während、wegen）口语常被三格替代，考试和书面语写二格；原文 "strotz" 是 trotz 的笔误。
