# German Grammar -Nominalisierung und Verbalisierung

> 中：名词化（从句 → 介词 + 名词）与动词化（反过来）。书面语、C1 写作常把从句压缩成名词短语；阅读时要能"解压"回从句。

## Zusammenfassung

| | Verbalform: Konnektor | Nominalform: Präposition |
|---|---|---|
| **konditional (Bedingung)** | wenn, falls, sofern — *Wenn man gutes Futter verwendet, …* | bei + Dat. — *Bei Verwendung von gutem Futter …* |
| | wenn … nicht — *Wenn die Kontrollen nicht erhöht werden, …* | ohne + Akk. — *Ohne Erhöhung der Kontrollen …* |
| **final (Absicht, Zweck oder Ziel)** | um … zu, damit — *Um das Vorhaben besser bewältigen zu können, …* / *Damit man das Vorhaben besser bewältigen kann, …* | zu + Dat. / für + Akk. — *Zur besseren Bewältigung des Vorhabens …* / *Für die bessere Bewältigung des Vorhabens …* |
| **temporal (Zeit)** | seitdem — *Seitdem die Steinkohle entdeckt wurde, …* | seit + Dat. — *Seit der Entdeckung der Steinkohle …* |
| | nachdem — *Nachdem der Krieg beendet worden war, …* | nach + Dat. — *Nach dem Ende des Krieges …* |
| | als — *…, als die Wirtschaft der Bundesrepublik wieder aufgebaut wurde.* | bei + Dat. — *… beim wirtschaftlichen Wiederaufbau der Bundesrepublik.* |
| | bis — *Bis der wirtschaftliche Abschwung begann, …* | bis zu + Dat. — *Bis zum Beginn des wirtschaftlichen Abschwungs …* |
| | bevor — *Bevor die Kohlekrise begann, …* | vor + Dat. — *Vor dem Beginn der Kohlekrise …* |
| | während — *Während man Kohle förderte, …* | während + Gen. — *Während der Kohleförderung …* |
| **kausal (Grund)** | weil, da — *Weil/Da die Konkurrenz stark ist, …*; deshalb, deswegen, darum — *Die Konkurrenz ist stark, deshalb …* | wegen + Gen. / aufgrund + Gen. — *Wegen der starken Konkurrenz …* / *Aufgrund der starken Konkurrenz …* |
| **modal (Art und Weise)** | indem — *…, indem sie Produktionsstätten ins Ausland verlegen.*; dadurch, dass — *Dadurch, dass sie Produktionsstätten ins Ausland verlegen, …* | durch + Akk. — *Durch die Verlegung von Produktionsstätten ins Ausland …* |
| **konzessiv (Gegengrund oder Einschränkung)** | obwohl — *Obwohl sie sehr motiviert sind, …*; trotzdem / dennoch — *Viele sind sehr motiviert, trotzdem/dennoch …*; zwar …, aber — *Sie sind zwar sehr motiviert, aber …* | trotz + Gen. — *Trotz großer Motivation …* |

> 中（条件）：wenn/falls/sofern（如果）→ bei + 三格：如果使用好饲料…… → 在使用好饲料的情况下……；wenn … nicht（如果不）→ ohne + 四格：如果不加强检查…… → 不加强检查的话……
> 中（目的）：um…zu / damit（为了）→ zu + 三格 / für + 四格：为了能更好地完成这项计划…… → 为更好地完成这项计划……
> 中（时间）：seitdem（自从）→ seit：自从发现了硬煤…… → 自发现硬煤以来……；nachdem（在…之后）→ nach：战争结束后……；als（当…时）→ bei：……当联邦德国经济重建时 → 在联邦德国经济重建时期；bis（直到）→ bis zu：直到经济衰退开始……；bevor（在…之前）→ vor：煤炭危机开始之前……；während（在…期间）→ während + 二格：在开采煤炭期间……
> 中（原因）：weil/da、deshalb/deswegen/darum（因为/所以）→ wegen / aufgrund + 二格：因为竞争激烈……
> 中（方式）：indem / dadurch, dass（通过……）→ durch + 四格：通过把生产基地迁往国外……
> 中（让步）：obwohl / trotzdem / dennoch / zwar…aber（尽管/虽然…但是）→ trotz + 二格：尽管干劲很足……

## Nominalisierung und Verbalisierung von Präpositionalergänzungen

> 中：带介词补足语的动词：名词形式里介词直接接名词；动词形式里介词变成代副词（dafür / darüber），后面接 zu 不定式或 dass 从句。

| Nominalform | Verbalform |
|---|---|
| Brainstorming **setzt** man **für** die Entwicklung neuer Ideen **ein**. | Brainstorming **setzt** man **dafür ein**, neue Ideen zu entwickeln. |
| Ihr Umfeld wird **sich** über Ihre Kreativität **freuen**. | Ihr Umfeld wird **sich (darüber) freuen**, dass Sie kreativ sind. |

> 中：人们用头脑风暴来开发新点子。（etw. für etw. einsetzen 把……用于……；动词化：dafür einsetzen, … zu entwickeln）
> 中：您周围的人会为您的创造力感到高兴。（sich über etw. freuen；动词化：sich (darüber) freuen, dass Sie kreativ sind——"Ihr/Sie"大写是"您"）

# 中文要点

- 名词化 = 把从句压缩成名词短语（Because he was ill → because of his illness），是德语书面语"高级感"的来源。
- 对应关系：wenn/falls → bei；wenn … nicht → ohne；um … zu/damit → zu/für；seitdem → seit；nachdem → nach；als → bei；bis → bis zu；bevor → vor；während → während + 二格；weil/da/deshalb → wegen/aufgrund + 二格；indem/dadurch, dass → durch；obwohl/trotzdem/zwar … aber → trotz + 二格。
- 介词的格要记对：bei、zu、seit、nach、vor、bis zu + 三格；ohne、für、durch + 四格；während、wegen、aufgrund、trotz + 二格。
- 介词宾语同理：für etw. einsetzen ↔ dafür einsetzen, … zu …；sich über etw. freuen ↔ sich (darüber) freuen, dass …。
- 现阶段先会"解压"（读懂 bei + 名词背后的 wenn 从句），再练"压缩"。
