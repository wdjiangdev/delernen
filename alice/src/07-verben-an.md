# German Verbs and Preposition 'an'

Verbs with "an + D" (Dative)

> 中：带 an 的动词（原文标题写"+ 三格"）。⚠ 并非全部是三格：denken an、glauben an、sich erinnern an、sich gewöhnen an、(sich) anpassen an 是 **an + 四格**；arbeiten an、sich orientieren an、sich beteiligen an、interessiert an、leiden an、liegen an、sterben an、zweifeln an、teilnehmen an、erkennen an、fehlen an、hängen an、ändern an 是 **an + 三格**。

Think of Connections or Attachments: Antennas connect (an) things together, so verbs with "an" often relate to connections or attachments.

> 中：联想"连接、依附"：天线（Antenne）把东西连在一起，所以带 an 的动词常和"连接、附着"有关。

- arbeiten an — (to work on)
  > 中：从事、致力于（+三格）：Ich arbeite an einem Projekt. 我在做一个项目。
- ändern an
  > 中：在……上做改动（+三格）：Wir müssen etwas an dem Plan ändern. 我们得改一改计划。
- anpassen an
  > 中：使适应、调整到（+四格）：Ich passe mich an die neue Situation an. 我适应新情况。（Duden：sich anpassen 也可以不带 an、直接接三格：sich der neuen Situation anpassen）
- sich beteiligen an — (to participate in)
  > 中：参与（+三格）：Sie beteiligt sich an der Diskussion. 她参与讨论。
- interessiert an
  > 中：对……感兴趣（+三格）：Er ist an Musik interessiert. 他对音乐感兴趣。
- leiden an — (to suffer from)
  > 中：患（病）（+三格）：Sie leidet an Asthma. 她患有哮喘。
- liegen an
  > 中：在于、归因于（+三格）：Das liegt am Wetter. 这是天气的缘故。
- sterben an — (to die of)
  > 中：死于（+三格）：Er starb an Krebs. 他死于癌症。
- zweifeln an — (to doubt)
  > 中：怀疑（+三格）：Ich zweifle an seiner Ehrlichkeit. 我怀疑他是否诚实。
- sich erinnern an — (to remember)
  > 中：记得、回想起（+四格）：Ich erinnere mich an den Urlaub. 我记得那次假期。
- sich orientieren an
  > 中：以……为导向/参照（+三格，常见 an + Dat.）：Wir orientieren uns an den Kunden. 我们以客户为导向。
- sich gewöhnen an — (to get used to)
  > 中：习惯于（+四格）：Ich gewöhne mich an das Essen. 我在习惯这里的饭菜。
- denken an — (to think of)
  > 中：想到、想念（+四格）：Ich denke oft an dich. 我常想你。
- glauben an — (to believe in)
  > 中：相信（+四格）：Sie glaubt an Gott. 她信上帝。
- teilnehmen an — (to participate in)
  > 中：参加（+三格）：Ich nehme an dem Kurs teil. 我参加这门课。
- erkennen an — (to recognize by)
  > 中：凭……认出（+三格）：Ich erkenne ihn an der Stimme. 我凭声音认出他。
- fehlen an — (to lack)
  > 中：缺少（无人称 es fehlt an + 三格）：Es fehlt an Geld. 缺钱。
- hängen an — (to depend on)
  > 中：依恋、舍不得（+三格）：Er hängt an seiner Heimat. 他眷恋家乡。（"取决于"一般用 abhängen von）
- die Reichtum an
  > 中：……的丰富（+三格）。⚠ 原文冠词有误：应为 **der** Reichtum an（阳性）：der Reichtum an Bodenschätzen 矿产资源丰富。
- die Schuld an
  > 中：对……负有责任（+三格）：die Schuld an dem Unfall 事故的责任。
- sterben an
  > 中：（重复）死于。
- zweifeln an
  > 中：（重复）怀疑。

> 中（小结）：an 的动词按格分两组记：四格组（denken / glauben / sich erinnern / sich gewöhnen / anpassen）与三格组（其余）。不要按原文标题一律记成三格。

# 中文要点

- an 的意象是"连接、依附"：参加、习惯、感兴趣都是把自己"连"到某件事上。
- 格要分开记：denken an、glauben an、sich erinnern an、sich gewöhnen an、sich anpassen an 是 an + 四格（anpassen 也可直接接三格：sich der Umgebung anpassen）；arbeiten an、teilnehmen an、leiden an、sterben an、zweifeln an 等其余搭配是 an + 三格。
- 介词不能按英语逐词对译（think of / believe in / get used to 在德语里都用 an），"动词 + 介词 + 格"整串背。
- 名词搭配：der Reichtum an（原文 die 是笔误）、die Schuld an + 三格。
